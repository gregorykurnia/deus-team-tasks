# C — Day strip

**Idea:** work arranged by time. A large date and a two-week strip show how busy each day is; under them the chosen day's calendar events sit beside its tasks.
**Moving around:** pick a day in the strip. A floating bar at the bottom (on phone and large screens) switches areas, with a round add button next to it.
**Density:** medium. Three columns on large screens (calendar, tasks, people) and one stacked column on phones.
**Type:** Sora for the big date and headings, Albert Sans for text.
**Colour:** white. The three kinds of work each have a soft tint (violet for prospects, green for clients, blue for internal); events are grey; red and orange show urgency.
