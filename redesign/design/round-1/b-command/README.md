# B — Command

**Idea:** a crisp control panel. Numbers come first: a strip of urgency counts on top, then one sortable table of everything that needs attention.
**Moving around:** horizontal tabs and a search field in a top bar on large screens; on phones, scrolling tab pills, a search icon and a floating "New task" button.
**Density:** medium-high. A table with columns you can choose, a side column for today's calendar and who's carrying what.
**Type:** Geist with tabular figures, 14 px base and a 28 px page title.
**Colour:** cool grey page with white panels and a cobalt accent. Work kinds are cobalt, green and slate tags; urgency is shown with pills and bars.
